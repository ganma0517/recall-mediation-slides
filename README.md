# 政黨認同與大罷免偏好：檢驗政策態度的中介效果

研討會發表用互動投影片（13 頁）。林文正，中央研究院社會學研究所博士後研究。

**線上瀏覽**：https://ganma0517.github.io/recall-mediation-slides/

## 內容

以 2025 年第一次社會意向調查（2025/6/2–6/22 全國電訪 1,239 人，位於 7/26 投票前一個月）檢驗政黨認同對大罷免偏好的影響，是否經由預算衝突、中國因素與美國因素三類政策態度所中介。
